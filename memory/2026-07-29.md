## Machina Article — Full Pipeline Log (23:41)

**Headline:** "one agent runs the film studio, you keep the taste."

### Taste Layer (Human Gates)
- Pick reference shots → you choose
- Approve frames → you pick keepers
- Final cut decisions → you cut the dead weight

### Agent Engine (Claude Code + Higgsfield CLI)

**Stage 1 — Style Contract**
- Vision model extracts lens, lighting, palette, grain from real film stills
- 5 checks: analyze composition, identify lens & focal length, profile lighting & contrast, extract color palette, measure grain & texture
- Output: one locked paragraph

**Stage 2 — Frames**
- Several diffusion models generate stills at volume
- Winners refined, characters and locations locked into reference sheets
- 5 checks: multi-model generation, rank & score every frame, refine top percent, build reference sheets, lock characters & locations
- Output: reference sheets locked
- Runs in parallel (subagent)

**Stage 3 — Shot Scripts**
- Model writes every prompt from one locked template
- One verb per shot, positive constraints only
- 5 checks: one locked template, one verb per shot, positive constraints only, no style drift, log every prompt
- Output: one script file

**Stage 4 — Motion**
- Image-to-video, isolated 3-5s shots
- Grammar: camera move + in-scene event + no frozen figures
- Auto quality gate
- Annotation: **"this is where slop dies"**
- Output: clean shot library
- Runs in parallel (subagent)

**Stage 5 — Montage**
- Score first, cut from a text file with ffmpeg
- Upscale finished master once to 4K
- 5 checks: compose temp score, edit from text file, ffmpeg assembly, single upscale to 4K, deliver final master
- Output: final 4K master

### Stage 1 Deep-Dive — Extract Taste from Cinema (23:43)
**Core philosophy:** "The fastest way to bring taste into AI video is to stop describing moods from imagination and start extracting them from shots that already worked on millions of people."

**Source reference libraries:**
- frameset.app — film/video stills, searchable by lens, lighting, movement
- shotdeck.com — frame-by-frame stills from almost any film
- fancaps.net — frame-by-frame stills
- savee.com — imagery and mood boards
- cosmos.so — imagery and mood boards
- eyecannndy.com — transitions and camera technique

**The extraction move:**
1. Pick 5-10 shots carrying the exact feeling you want
2. Feed each to a vision model (Gemini 3.1 Pro)
3. Have it name the shot's parameters in extreme detail: lens feel, lighting direction and source, palette, grain, contrast, blocking, atmosphere, era markers

**The output:** A style contract — one locked paragraph of visual language pasted into every image and video prompt, word for word. Every generation pulls toward the same film.

**Key insight:** "cinematic" is the single most wasted word in AI video. Models have seen 10M images tagged with it — it means nothing. Reinforcement pairs are what land: "motivated warm lighting, 35mm grain, shallow depth of field, lifted blacks."

**Rule:** That one paragraph decides how everything downstream looks.

### Stage 2 Deep-Dive — Frames Before Motion, Always (23:45)
**Core philosophy:** Never generate video from imagination. Generate still frames until the frame is right, then animate the winner. A frame costs a fraction of a clip and takes seconds instead of minutes — all exploration happens at the cheap layer.

**The frame pass:**
- Run the same shot brief through several diffusion models side by side with the style contract attached
- Try a LOT of frames per beat: different compositions, different moments inside the scene, different weather
- Refine winners: Nano Banana for surgical edits and consistency passes, Soul Cinema for photographic character looks, GPT-Images-2 for dense art direction

**Locking reference sheets:**
- One per character: front, three-quarter, profile, cropped separately (grids confuse video models into reading panels as different people)
- Separate sheet per wardrobe or state change
- Multi-angle sheets per location

**Supercomputer option:** Tests same brief across models automatically, looks at outputs, iterates without monitoring.

**Three frame rules:**
1. Objects hold emotion better than faces — faces drift between generations, objects lock. When a beat can land on a torn sail or broken oar instead of an expression, hand it to the object.
2. One impossible thing in one normal place — the composition that stops a scroll.
3. Give the character a cost — a figure walking is footage, a figure limping toward something is a story.

**Bridge to Stage 3:** Frames are only half the job. A beautiful frame that doesn't move is still slop.

### Stage 3 Deep-Dive — The Agent Writes the Shot Scripts (23:46)
**Tool:** Fable 5 Medium as the script writer.
**Input:** Beat sheet + style contract.
**Output:** Every shot's prompt in one locked template — scene context, references, blocking, camera, lighting, audio, style locks, same order every time.

**Why locked:** Consistency across shots comes from repeated reference images and repeated language, never from seeds or luck.

**The prompt rules:**
1. One verb per shot — "he turns" generates, "he turns, walks forward, reaches out and speaks" collapses
2. Five small actions land better than one adjective — "blank stare, slow blink, sips coffee, looks up" reads as a person, "he looks confused" reads as a stock photo
3. Subject movement and camera movement always get separate sentences — one clause carrying both is how you get the shaky nonsense
4. T2V prompts: 120-280 words. I2V prompts: under 80 words (past that, text fights the image and character drifts)
5. Positive constraints only — "stable picture, sharp clarity" works, "no blur, no shaking" gets ignored

### Stage 4 Deep-Dive — Motion, and the Grammar That Kills Frozen Shots (23:47)
**Tool:** Seedance 2.0 image-to-video.
**Format:** Each keyframe → isolated 3-5 second shot. A minute of film = 12-16 shots stitched. An editor cuts shots, not takes.

**Why shot isolation:** Identity drift shows up past 30 seconds of continuous scene. Isolated beats never get there.

**The grammar (3 parts, every I2V prompt):**
1. A named camera move
2. An in-scene event — something HAPPENS during the five seconds
3. An explicit "no frozen figures"

**Example:** "slow dolly in, cinematic" → still image that drifts.
"slow dolly in as the sail tears loose and the crew scrambles to catch it" → a film.

**Two motion techniques:**
1. Chain shots: last frame of shot N becomes reference frame of shot N+1 — continuity carries forward without reloading character sheets
2. Time-code the climax inside one generation: [0-4s] wide and static, [4-8s] push-in as tension builds, [8-12s] close-up at the peak, [12-15s] the reveal — directing cuts inside a single clip

**Volume reality:** One good clip is a sample. A film needs sixty of them.

### Stage 5 Deep-Dive — The Fleet (23:48)
**Core:** "This is the stage where Claude Code earns the word studio."

**Structure:**
- One orchestrator session owns the shot list
- Spawns subagents by shot family: creatures, water, interiors, action
- Each subagent: writes prompts from style contract → submits via CLI → polls jobs → reports winners
- Because every model is addressable from the same terminal, the fleet covers the full shot list in parallel, across models

**The one rule:** Respect concurrency. Agent checks active jobs, submits only when a slot frees.
- An agent that throttles finishes overnight
- A naive loop dies on rate limits an hour in
- The cap is what makes the overnight run predictable

**Iteration discipline:**
- 3-4 candidates per shot
- Change ONE variable per pass (camera, lighting, or speed)
- Never a full rewrite — a fail you changed five things on teaches you nothing

**Logging:**
- Every generation logged: prompt, model, result, kept or killed
- "Your production becomes a database, and production number two starts from everything number one learned"

### Stage 6 Deep-Dive — Montage as Code (23:49)

**Music first:** Brief the score against the cut's emotional arc in movements (build → peak → quiet → resolve), not moods. Generated in one pass, then trim the cut to the score.

**The cut is a text file:** One line per clip with duration and audio flag. ffmpeg reads the file and renders the film.

```
shot_name duration audio_flag
17-scylla-deck 3.2 mute     # generated shout fought the strings
sea-ambience   4.1 live     # sells the scene
```

Per-clip audio mutes exactly where it collides with the score, kept everywhere it adds realism. Entire edit is reproducible and changeable in seconds — no timeline software, no editor.

**Upscaling rule:**
- 720p while exploring
- 1080p for keepers
- 4K ONLY for the final master, never on individual clips
- Stop at the lowest resolution that answers the question you're asking

**Last cut pass:** Any clip where you'd check your phone gets deleted, whatever it cost you.

**Supercomputer option:** Hand it the winning clips, it assembles the cut and renders the 4K master itself.

1. Extract a style contract from real cinema with a vision model
2. Generate frames at volume across several diffusion models, refine, lock characters and locations into sheets

- A standing system wins on speed: when a moment hits, the window is measured in hours. An operator with a style contract, locked characters, and a generation fleet publishes while everyone else is opening tabs.

### The Three Loops (same as schematic)
- Shot loop: change one variable per pass
- Fleet loop: submit when a slot frees
- Session loop: log everything

### Concurrency

- Throttled by concurrency cap: max N jobs at a time
- "Keeps the pipeline full, not flooded."
